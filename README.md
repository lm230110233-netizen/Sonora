# Sonora (fase 1 + extras)

App web para escuchar música, hecha con HTML y Tailwind CSS siguiendo el sistema de diseño de Sonora. La reproducción es simulada: no hay audio real.

## Cómo ejecutarla
1. Descarga la carpeta `sonora`.
2. Abre `index.html` en el navegador (doble clic). No necesita instalar nada.
3. Necesita internet para cargar Tailwind (CDN) y las fuentes Manrope y JetBrains Mono.

## Qué incluye
- Obligatorio: pantallas Inicio, Playlist y Reproductor, con navegación entre ellas.
- Extras: Buscar, tema claro y versión móvil (390px).
- Datos propios: 8 canciones y 4 playlists inventadas.
